## 💡 My Core Strategies & Rules

1. **The 45-Minute Rule:** Spend at least 45 minutes whiteboarding and brainstorming a conceptual solution manually before looking up hints or video explanations.
2. **Dry Run First:** Always trace code iterations on paper using a pen to map call stacks, pointers, and variables dynamically.
3. **Complexity Engineering:** Every single solution committed in this repository includes a commented analysis of its **Time Complexity $O(N)$** and **Space Complexity $O(1)$**.
4. **Pattern Recognition over Rote Learning:** The focus is on master patterns (like Slidding Windows, Frequency Counters) rather than memorizing individual platform questions.
